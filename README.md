# ROBSPACE

## 1. Deskripsi Masalah

Perkembangan industri event dan nightlife membuat pengguna membutuhkan informasi event yang mudah diakses melalui perangkat mobile. Informasi seperti jadwal event, lokasi, lineup DJ/MC, pemesanan meja, dan pendaftaran guest list sering kali tersebar melalui media sosial atau aplikasi pesan sehingga pengguna harus mencari informasi dari beberapa tempat.

Selain itu, proses pemesanan meja dan pendaftaran untuk menghadiri event masih dapat dilakukan secara manual melalui komunikasi dengan pihak penyelenggara. Hal tersebut dapat menyebabkan informasi yang diterima pengguna tidak terstruktur dan menyulitkan penyelenggara dalam mengelola data pengunjung.

ROBSPACE merupakan aplikasi mobile yang dirancang sebagai platform informasi dan layanan event. Aplikasi ini menyediakan informasi event secara terpusat serta memungkinkan pengguna melakukan pemesanan meja (table booking), pendaftaran guest list, dan hosting melalui perangkat mobile.

Aplikasi ini dikembangkan sebagai project yang realistis untuk diselesaikan dalam 12 kali pertemuan dengan fokus pada fitur inti dan pengalaman pengguna.

---

## 2. Profil Target Pengguna

### Pengguna Utama

Target utama ROBSPACE adalah:

- Pengunjung event dan nightlife.
- Pengguna yang ingin mengetahui informasi event.
- Pengguna yang ingin melakukan pemesanan meja.
- Pengguna yang ingin mendaftar sebagai guest list.
- Pengguna yang ingin melakukan hosting untuk event.

### Karakteristik Pengguna

Pengguna diharapkan:

- Menggunakan smartphone dalam aktivitas sehari-hari.
- Membutuhkan akses cepat terhadap informasi event.
- Terbiasa menggunakan aplikasi mobile.
- Membutuhkan proses booking dan registrasi yang sederhana.
- Membutuhkan informasi event seperti tanggal, lokasi, lineup, dan harga meja.

### Pengelola Event

Selain pengguna umum, pihak penyelenggara event dapat menggunakan sistem pengelolaan data untuk mengelola informasi event, meja, guest list, hosting, dan dokumentasi event.

## 3. Manfaat Aplikasi

ROBSPACE memberikan beberapa manfaat utama:

1. Menyediakan informasi event dalam satu aplikasi.
2. Memudahkan pengguna melihat detail event seperti tanggal, lokasi, dan lineup.
3. Memudahkan pengguna melakukan pemesanan meja.
4. Memudahkan pengguna melakukan pendaftaran guest list.
5. Memudahkan pengguna melakukan hosting.
6. Mengurangi proses pendaftaran yang dilakukan secara manual melalui pesan pribadi.
7. Membantu penyelenggara mengelola data booking dan registrasi pengguna secara lebih terstruktur.
8. Menyediakan informasi dokumentasi atau foto event kepada pengguna.

---

## 4. Daftar Fitur Inti

Fitur inti ROBSPACE yang direncanakan adalah:

### 1. Login dan Register

Pengguna dapat membuat akun dan masuk ke aplikasi menggunakan akun yang telah terdaftar.

### 2. Home

Menampilkan informasi utama mengenai event yang sedang tersedia, termasuk flyer dan informasi singkat event.

### 3. Event Information

Pengguna dapat melihat:

- Nama event.
- Tanggal event.
- Lokasi event.
- Waktu event.
- Lineup DJ.
- Lineup MC.
- Informasi tambahan mengenai event.

### 4. Table Booking / RSVP

Pengguna dapat:

- Melihat daftar meja yang tersedia.
- Melihat kapasitas meja.
- Melihat harga meja.
- Melihat informasi bottle package.
- Melihat floor plan meja.
- Memilih meja.
- Mengirimkan permintaan booking.

### 5. Guest List

Pengguna dapat mendaftarkan diri sebagai guest list dengan mengisi informasi yang diperlukan.

### 6. Hosting

Pengguna dapat melakukan pendaftaran hosting dengan memasukkan data anggota yang akan datang.

### 7. My Tickets / My Booking

Pengguna dapat melihat data booking atau pendaftaran yang telah dilakukan serta statusnya.

### 8. Photos

Pengguna dapat melihat dokumentasi foto dari event yang telah berlangsung.

### 9. Profile

Pengguna dapat melihat informasi akun dan melakukan logout.

### 10. Admin Management

Pihak admin dapat mengelola informasi event, meja, booking, guest list, hosting, dan dokumentasi event melalui sistem pengelolaan yang terhubung dengan aplikasi.

## 5. Fitur yang Tidak Dikerjakan

Untuk menjaga agar project tetap realistis diselesaikan dalam 12 pertemuan, beberapa fitur tidak menjadi fokus pada versi pertama ROBSPACE.

Fitur yang tidak dikerjakan:

- Sistem pembayaran online secara langsung.
- Integrasi payment gateway.
- Sistem chat antara pengguna dan admin.
- Sistem rekomendasi event berbasis AI.
- Sistem navigasi dan tracking lokasi secara real-time.
- Sistem live streaming event.
- Sistem penjualan tiket kompleks dengan berbagai kategori tiket.
- Integrasi otomatis untuk memverifikasi pengguna mengikuti akun Instagram.
- Sistem analisis bisnis dan laporan keuangan yang kompleks.
- Sistem multi-cabang atau multi-organisasi yang kompleks.

Fitur-fitur tersebut dapat dipertimbangkan untuk pengembangan versi berikutnya.

## 6. Kriteria Aplikasi Dinyatakan Berhasil

Aplikasi ROBSPACE dinyatakan berhasil apabila:

1. Aplikasi dapat dijalankan pada perangkat mobile atau emulator.
2. Pengguna dapat melakukan login dan register.
3. Pengguna dapat melihat informasi event.
4. Pengguna dapat melihat detail event dan lineup.
5. Pengguna dapat melihat daftar meja dan floor plan.
6. Pengguna dapat melakukan proses table booking.
7. Pengguna dapat melakukan pendaftaran guest list.
8. Pengguna dapat melakukan pendaftaran hosting.
9. Data pendaftaran dapat tersimpan dengan benar.
10. Pengguna dapat melihat data booking atau pendaftaran yang telah dibuat.
11. Pengguna dapat melihat dokumentasi foto event.
12. Validasi input berjalan dengan baik.
13. Aplikasi dapat memberikan informasi loading, berhasil, kosong, dan error pada kondisi yang sesuai.
14. Tidak terjadi double submission ketika pengguna menekan tombol submit berulang kali.
15. Fitur utama dapat digunakan tanpa menyebabkan aplikasi mengalami crash.
16. Struktur project menggunakan pemisahan screen, widget, model, service, dan routing sehingga mudah dikembangkan.
