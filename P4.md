# P4 - Feature Flutter ROBSPACE

## 1. Nama Feature

Event Registration ROBSPACE

Feature ini digunakan untuk menampilkan daftar event dan menyediakan form pendaftaran event.

## 2. Tujuan Feature

Feature dibuat untuk menerapkan:

- State management menggunakan Riverpod
- Pemisahan repository, notifier, dan widget
- Form input dan validasi
- Loading state
- Success state
- Empty state
- Error state dengan tombol retry
- Loading saat submit
- Pencegahan double tap saat proses submit
- Widget testing
